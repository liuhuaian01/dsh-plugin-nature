# nature · 中文写作体检

对一段中文做**确定性扫描**（不调模型、不联网），输出模板腔指数、命中清单、用字错误和改写处方。真正的改写由你完成——脚本只负责检查和开方。

## 什么时候用

- 写完一稿想确认有没有套路化写法
- 审别人交来的文字
- 拿到一段读着别扭、但说不出哪里别扭的稿子
- 改稿前做一次体检

## 它不是 AI 检测器

**它衡量的是文本的模板化程度，不是作者身份。真人写作同样会命中这些模式。**

这条必须说清楚，因为它被误用过三次：一段 100% 手写的小说被判「明显的 AI 腔」，一段专业作家的成名作被判有问题，一篇虎嗅编辑的稿子被判 32 分——全都是把文体惯例当成了缺陷。

**不要用它下「这段是 AI 写的」这种结论。** 也不要把「模板腔指数高」等同于「质量差」。

## 怎么跑

```bash
node "${CLAUDE_SKILL_DIR}/scripts/nature.mjs" <文件> --genre=<文体> --out=<报告文件>
```

Windows 控制台编码不稳，**建议始终用 `--out` 写到文件再读**：

```bash
node "${CLAUDE_SKILL_DIR}/scripts/nature.mjs" draft.md --genre=media --out=.nature-report.md
```

从 stdin 读、从管道接：

```bash
cat draft.md | node "${CLAUDE_SKILL_DIR}/scripts/nature.mjs" - --genre=news
```

先看有哪些文体：`node "${CLAUDE_SKILL_DIR}/scripts/nature.mjs" --list`

支持的文体：

| id | 适用 |
|---|---|
| `general` | 日常对话与通用说明 |
| `media` | 自媒体推文：公众号、小红书 |
| `script` | 口播稿、视频脚本 |
| `fiction` | 小说、故事、剧本（出版向） |
| `webnovel` | 网络小说连载 |
| `business` | 财经、商业分析 |
| `news` | 新闻稿、媒体报道 |
| `commentary` | 分析评论、专栏 |
| `report` | 报告、公文、商务邮件 |
| `tech` | 技术文档与技术博客 |
| `proposal` | 方案策划、提案、品牌/营销/产品方案 |

传了不认识的 id 会回落 `general`。

**文体选错，结论就会错。** 这是这套脚本最容易出问题的地方——排版惯例随平台变，不是写作水平。如果报告里出现「文体提示」一行，说明换个体文体会宽松很多，照它说的重跑一次。

## 报告怎么读

分数分三段：

- **模板腔信号**（计入分数）——套话连接词、万能背景、升华结尾、行业黑话、翻译腔、节奏碎片。这些是真人写小说和新闻几乎不会这么写的东西。
- **文字错误**（不计分）——错别字、「的／地」误用。谁写的都该改，跟「像不像机器写的」无关。
- **编辑建议**（不计分）——情绪直陈、排版、ASCII 标点。口味问题，按文体取舍。

**指数 0–19 是 A，20–39 是 B，40–59 是 C，60–79 是 D，80 以上是 E。** 但分数只是入口，真正要读的是命中清单里的 `为什么是问题` 和 `怎么改`。

## 改写原则

### 直接删掉

- **公文过渡语**：值得注意的是、需要指出的是、综上所述、总而言之、换言之、与此同时、由此可见、不难发现
- **万能背景**：在当今社会、随着科技的发展、在这个快速变化的时代、在……的大背景下
- **升华收尾**：让我们共同、相信在不久的将来、这正是……的意义所在、值得我们深思
- **空转动词**：进行讨论、加以优化、作出决定 → 直接写讨论、改进、定下来
- **抽象黑话**：赋能、抓手、闭环、颗粒度、对齐、沉淀、落地、心智、范式 → 翻译成具体的人和事
- **概括形容词**：丰富的、独特的、深刻的、全面的、系统的 → 删掉，或换成能被验证的细节

### 分清两种长

这是最容易被搞错的一条。

**该拆的**是定语堆叠的欧化长句：
> 一个在县城长大、后来去深圳打工、最后又回到老家开店的年轻人
> → 他在县城长大，后来去深圳打工，最后回老家开了个店。

**不该拆的**是意合的流水句：
> 他推开门，屋里没人，桌上放着半杯凉掉的茶，杯壁上有一圈茶渍。

用逗号串起一串小句、最后才落句号，是成熟的中文。把它切成「他推开门。屋里没人。桌上放着半杯凉掉的茶。」才是写坏了。

判断只有一条：出声读一遍。不该换气的地方换了气就拆，读着顺就别动。

### 节奏

有一类模型把「简洁」理解成「句子要短」，写出来全是三五字的短句、一句一段。这和欧化长句是同一个病的两个极端。

- 关系紧密的小句用逗号连着写，只在意思真正结束的地方落句号
- **长短交错**，不是一律短。短句的分量来自它周围有长句
- 中文可以承前省略主语，连着几句讲同一个人不必每句都补「他」

### 先定结构，再看句子

段落放什么、先后顺序，比句子怎么写更早决定像不像那个文体。结构错了，句子再干净也不像。

| 文体 | 按这个顺序写 |
|---|---|
| 日常 | 第一句给答案 → 理由一到三条 → 边界或下一步 |
| 自媒体 | 前十五字给一个具体场景、反常识或真实数字 → 为什么值得看，每条配可核对的东西 → 读者能带走的一句话或动作 |
| 口播 | 前三秒说清讲什么或抛反常识 → 两三个点，先结论后原因，关键信息说两遍 → 回扣开头 |
| 小说 | 先给场景：时间、地点、此刻在发生什么 → 动作和对话推进，不解释心理 → 结束时有什么变了 |
| 网文 | 开篇直接进事件 → 障碍加深或出现新变数 → 结尾留问题、威胁或反转 |
| 报告 | 结论第一段 → 依据：数字、时间、责任人 → 风险别藏 → 下一步谁做、什么时候 |
| 技术 | 前提：版本、平台、依赖 → 步骤一步一条 → 预期看到什么 → 不通时先查什么 |
| 新闻 | 导语：谁、做了什么、何时、何地 → 细节和数字，按重要性递减 → 信源 → 有争议时并列另一方 |
| 财经 | 数据带来源和时间点 → 判断这些数字意味着什么 → 什么情况下判断会错 → 和上季度、和同行比 |
| 评论 | 开头亮判断 → 事实加推理，每条事实可核对 → 最强反方为什么不成立 → 收在判断上 |
| 方案 | 第一段：要做什么、为什么、怎么做 → 可量化目标带时间 → 策略是选择，说清放弃什么 → 动作、谁做、什么时候 → 预算与验收 |

### 按文体再看一眼

同一个写法，在一个文体里是毛病，在另一个文体里是行话。动笔前先对一下自己写的是哪一类。

| 文体 | 模板腔 | 正常中文 |
|---|---|---|
| 日常 | 在当今社会，随着科技的飞速发展，人工智能已经深刻地改变了我们的生活方式。 | 手机里那个会说话的助手，三年前还只会查天气，现在能帮你订机票了。 |
| 自媒体 | 值得注意的是，这一现象背后蕴含着深刻的社会意义。 | 有意思的是，评论区吵得最凶的那批人，其实都没看完。 |
| 口播 | 综上所述，我们可以看到，人工智能技术正在深刻影响各个行业的发展。 | 你看现在做图的、写文案的、剪视频的，哪一行没被AI掺一脚？ |
| 小说 | 他的内心充满了复杂的情绪，既有对过去的不舍，也有对未来的迷茫。 | 他把烟按灭在窗台上。烟灰掉下去，没落地就被风吹散了。 |
| 网文 | 他心中暗自发誓，一定要让所有看不起他的人付出代价。 | 他咬了口冷馒头，把那张纸条揣进怀里。三年后回来，他要让这个铺子姓陈。 |
| 报告 | 本次工作取得了显著成效，为公司的发展奠定了坚实基础。 | 全年交付 47 个项目，按期率从 71% 提到 89%。延期集中在三家供应商。 |
| 技术 | 该系统具有较高的可扩展性和良好的可维护性。 | 加一个新数据源只需要改一个配置文件，不用动代码。 |
| 新闻 | 此次会议的召开，对于推动行业高质量发展具有十分重要的意义。 | 会上通过了三项标准，其中两项明年一月起实施。 |
| 财经 | 该公司业绩表现亮眼，营收和利润均实现了大幅增长。 | 营收 42 亿，同比增 31%；净利 3.7 亿，但经营现金流只有 1.2 亿。 |
| 评论 | 这一现象值得我们深思。 | 问题在于，做这件事的人越多，能赚到钱的人反而越少。 |
| 方案策划 | 本次营销活动将围绕品牌调性，通过多渠道联动，实现品效合一。 | 目标是把复购率从 18% 提到 25%。做法只有一条：把首单赠品换成第二次下单才能用的券。 |

看出规律没有：右边全都有一个**能被看见或能被核对的东西**——一个动作、一个数字、一句原话。左边全在说「这件事很重要」，但没告诉你是谁、多少、什么时候。

### 改完自检

1. 有没有一句话，换成别的主题也成立？有就删
2. 有没有连续三句长度接近？有就拆一句或并一句
3. 最后一段是不是在升华？是就整段砍掉
4. 通篇有没有一个数字、一个时间、一个具体的人？没有就补，补不出说明这段没内容
5. **数一下逗号和句号。** 句号比逗号多，说明切碎了
6. **出声读一段。** 读起来像念字卡，就是碎片化

## 硬约束

- 不得新增原文没有的事实、数字、人名或结论。缺信息就留空，**不要编**
- 不得把长句一律拆成短句
- 不得为了去味而堆口语词。目标是普通人在说事，不是模仿网红
- 改完保留原文的事实、数字、结论和当事人立场

## 输出格式

改写结果直接给正文，不要附诊断过程、不要对比表、不要说「以下是改写」。用户要看诊断时再说。
