# nature · 中文写作体检

对中文稿做**模板腔体检**，并给出按文体定制的改写处方。

规则库和扫描引擎是确定性的（不调模型、不联网），所以快、免费、可解释——每一分的扣分都能追到某条具体规则上。

## 三部分组成

| 部分 | 文件 | 作用 |
|---|---|---|
| **常驻规则** | `rules/nature-chinese.md` | `alwaysApply: true`，每一轮都在场。让模型默认就按「说人话」写，不必每次提醒 |
| **技能** | `skills/nature/SKILL.md` | 按需加载。完整方法论：十种文体的写法差异、改写原则、自检表 |
| **工具** | `skills/nature/scripts/nature.mjs` | 命令行扫描。给出模板腔指数、命中清单、用字错误、改写处方 |

## 用法

```powershell
$s = "$env:USERPROFILE\.workbuddy\plugins\marketplaces\my-experts\plugins\nature\skills\nature"
node "$s\scripts\nature.mjs" 稿件.md --genre=media --out=报告.md
```

Windows 控制台编码不稳，**始终用 `--out` 写到文件再读**。

查所有文体：`node "$s\scripts\nature.mjs" --list`

十一个文体：`general`（日常说明）、`media`（自媒体推文）、`script`（口播稿）、`fiction`（小说）、`webnovel`（网文）、`business`（财经商业）、`news`（新闻稿）、`commentary`（评论专栏）、`report`（报告公文）、`tech`（技术文档）、`proposal`（方案策划）。

**文体选错，结论就会错。** 排版惯例随平台变，不是写作水平——一句一段在起点和虎嗅是常态，在年报里是异常。

## 报告分三段

- **模板腔信号**（计入分数）——套话连接词、万能背景、升华结尾、行业黑话、翻译腔、节奏碎片
- **文字错误**（不计分）——错别字、「的／地」误用。谁写的都该改
- **编辑建议**（不计分）——情绪直陈、排版、ASCII 标点。口味问题

指数 0–19 是 A，20–39 是 B，40–59 是 C，60–79 是 D，80 以上是 E。

## 它不判断作者身份

**这一条最重要。**

它衡量的是文本的模板化程度，不是「这段是不是 AI 写的」。真人写作同样会命中这些模式。

这个插件被误用过三次：一段 100% 手写的小说被判「明显的 AI 腔」，一段专业作家的成名作被判有问题，一篇虎嗅编辑的稿子被判 32 分——全都是把文体惯例当成了缺陷。

**不要用它下「这段是 AI 写的」这种结论。**

## 依赖

只需要 Node.js（>= 18）。无第三方依赖，不联网，除 `--out` 指定的文件外不写磁盘。
